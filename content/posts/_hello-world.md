Every site starts somewhere. This one starts here.

## Why a personal site?

I've been meaning to build a proper home on the web for years. A place for longer thoughts than a Bluesky post, a place to document things I've figured out, and a place that feels genuinely *mine*.

This site is that place.

## What to expect

Writing will be irregular and range across:

- **Development** — tooling, architecture, things I've built or broken
- **Tools** — software, hardware, workflows that have changed how I work
- **Miscellaneous** — anything else that seems worth putting into words

Posts won't follow a schedule. They'll appear when something is worth saying.

## The stack

If you're curious about the technology behind the site, it's built with:

- **Nuxt 4** in full-static mode
- **Nuxt Content** for markdown-based authoring
- **BootstrapVueNext** for UI components
- **Three.js + Spark** for the Gaussian splat backgrounds

Source will eventually be on GitHub. More on that in a future post.
